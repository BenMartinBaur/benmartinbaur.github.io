# Post 05 - Routing Policy: Your Fastest Quality-Cost Compounding Lever (Business)

## Hook
Defaulting every task to premium models is not strategy. It is margin erosion.

## Body
Routing policy is where finance and engineering align:
1. Low-complexity tasks -> lower-cost model tier
2. High-risk reasoning tasks -> advanced model tier
3. Escalate only when quality or confidence thresholds fail

A practical governance pattern:
1. Balanced mode for default workloads
2. Cost mode for high-volume, lower-criticality paths
3. Quality mode for high-risk decisions
