# Post 03 - FinOps for Agents Starts with Attribution, Not Austerity (IT)

## Hook
If spend is not attributable, optimization will stay political and slow.

## Body
Start with attribution before optimization.
Track one anchor metric: **Cost per successful AI outcome**.

Practical implementation pattern:
1. Capture token usage by app, team, workflow, and model
2. Track outcomes (success, partial, failed) and run success rate
3. Roll up spend by workflow and business outcome, not model alone
4. Run a five-loop cadence: estimate -> enable -> monitor -> optimize -> govern

This aligns engineering changes with business value in one dashboard.
