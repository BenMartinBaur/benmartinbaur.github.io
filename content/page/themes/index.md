This page is the taxonomy map for the blog.

- **Themes** describe enduring outcomes and leadership questions.
- **Categories** describe the content lens used in a post.

## Theme-to-category mapping

### Enterprise Architecture

- Primary category fit: **Build**
- Typical post intent: technical patterns, implementation details, architecture decisions
- Browse: [Tag: enterprise-architecture](/tags/enterprise-architecture/) · [Category: Build](/categories/build/)

### AI Strategy

- Primary category fit: **Strategy**
- Typical post intent: operating model, value realization, governance, sequencing
- Browse: [Tag: ai-strategy](/tags/ai-strategy/) · [Category: Strategy](/categories/strategy/)

### Leadership at Scale

- Primary category fit: **Real** and **Strategy**
- Typical post intent: influence, cross-functional execution, leadership mechanisms
- Browse: [Tag: leadership-at-scale](/tags/leadership-at-scale/) · [Category: Real](/categories/real/)

### Career Growth

- Primary category fit: **Real**
- Typical post intent: growth patterns, lessons learned, practical career decisions
- Browse: [Tag: career-growth](/tags/career-growth/) · [Category: Real](/categories/real/)

## How to navigate

1. Start with **Themes** if you care about long-term outcomes.
